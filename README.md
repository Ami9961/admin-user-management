# Admin User Management

This project is a full-featured **Admin User Management** system, allowing admin users to manage, create, edit, and delete users easily.

## Features

- User Registration and Authentication
- Admin Dashboard
- Edit, Delete, and Create User Profiles
- Integrated **Live Forex Price API** using [Twelve Data API](https://twelvedata.com/)
- Form Validations and Alerts
- Responsive Frontend using Bootstrap

## Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **API Integration:** Twelve Data (for live forex price fetching)

## How to Run

1. Clone this repository:
    ```bash
    git clone https://github.com/Ami9961/admin-user-management.git
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Create a `.env` file with your environment variables (like MongoDB URL, TwelveData API key).
4. Run the app:
    ```bash
    npm start
    ```
5. Visit `http://localhost:3000` in your browser.
